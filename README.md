## 三个使用场景

我在 Codex 里聊过、做过的事情越来越多，窗口也越积越多。后来发现，困难不只是“窗口太乱”：有些事忘了继续，有些方案找不回来，同一件事的来龙去脉也散在不同地方。这个工作台，就是为了解决下面三个场景，一点点做出来的。

### 1. 有些事情还可以继续，但我已经忘了

窗口里可能留着尚未结束的事情、做到一半的项目，或聊到一半还想深入的话题。隔了几天再打开 Codex，往往已经想不起之前做到了哪一步，也不知道哪些事情可以接着做。

**“可以接着做”把这些讨论停点整理出来**，让你重新看见它们。进展不明确的会放在默认展开的“进展待确认”。你可以把它移入接续事项；已经在别处处理完的，也可以移出，不用专门回到原窗口补一句“做完了”。

![可以接着做：上方列出明确的下一步，下方展开待确认事项，并提供移入或不再显示的操作](docs/images/workbench-tasks.jpg)

*一眼看清停在哪里、还差什么；AI 无法确认的进展也不会藏起来。*

### 2. 明明聊过，却找不到在哪个窗口

我用 Codex 搜索时，遇到过等待很久、记不准原话就搜不到的情况。只看窗口名字也不够：一个窗口里经常接连做了好几件事，标题只能提示其中一部分。

**工作台按事情整理，并搜索已收录的讨论正文**。输入几个关键词或一句大概描述，先认出相关事情，再看匹配片段、日期和原话。找东西不再只靠回忆窗口叫什么；相近候选也能展开核对，但不保证每种说法都能命中。

![搜索结果：输入记得的“绿色”，找到网站改版中的配色决定和对应讨论日期](docs/images/workbench-search.jpg)

*例如只记得“当时选了绿色”，不记得窗口名，也能沿关键词找到这件事，再点进对应讨论。*

### 3. 想看清一件事怎么发展，也想回看某一天做了什么

同一件事可能在几个窗口里推进，前后又改过方向。只翻单个窗口，很难拼出完整经过。

**按事情看：不仅找到窗口，还能回忆当时为什么这样做。**

“事情总览”把同一目标的讨论合在一起。进入详情后，可以先读当前小结，再展开“决定与变化”：原来想做什么、后来改了什么、已经确认了什么、下一步是什么。每条决定都能点回对应讨论，核对当时的原话。

![讨论详情：上方是事项小结和三条决定与变化，左侧是跨日期讨论经过，右侧是对应小结与原话](docs/images/workbench-detail.jpg)

*这张图里，同一件事经历了“收窄范围 → 确定配色 → 留下下一步”。不必从头翻三个窗口，也能重新接上思路。*

**按日期看：快速回顾某一天都聊了什么。**

“每日回顾”按天展示讨论的小结与变化。比如选择“昨天”，就能一起看到网站改版、资料同步和阅读分享；需要细看时，展开当天的讨论，或点击事情进入详情。

![每日回顾：选择昨天，集中查看同一天三件事的变化和当天来源](docs/images/workbench-daily.jpg)

*事情总览展示一件事的全部来源；每日回顾展示当天的进展与当天来源。一个看经过，一个回看某一天。*

### 想过几天再看，先放进收藏

找到有用的方案或暂时想回看的事情，点一下 ☆，就能在“收藏”页集中找到。它是轻量的临时标记，不用再建一套任务清单。

![收藏：临时保留个人网站改版与阅读分享，下次直接回看](docs/images/workbench-favorites.jpg)

收藏保存在当前浏览器。普通重启通常不会丢失；换浏览器不会同步，清除本站数据后会丢失。页面里也保留了保存说明。

**找到以后，一键回到 Codex。** 上面各页中带 ↗ 的来源对话名都可以点击，打开对应的 Codex 窗口，继续讨论或查看完整现场。小结帮你认出事情，原话帮你核对，来源入口让你回去接着做。

## 开始使用

你需要在电脑上使用支持本地 Skill 的 Codex。**Skill 就是一套交给 Codex 执行的操作流程**，安装和整理都可以让它帮你完成，不用自己写代码。

### 1. 把这段话发给 Codex

新建一个对话，复制下面这段发送：

```text
请安装这个 Skill，并带我完成首次初始化：
https://github.com/LuKK351/lukk-codex-workbench
```

### 2. 选择先整理哪些讨论

Codex 会让你确认时间范围、保存位置和分类。保存位置与分类都有建议，可以直接沿用。

建议从 **近 1 个月** 开始，先看看整理效果；如果你只是偶尔使用 Codex，也可以选近 3 个月。想找更早的内容，可以直接指定日期。

<details>
<summary>不知道选多长时间？展开看看适合你的范围</summary>

| 整理范围 | 适合的情况 | 建议 |
| --- | --- | --- |
| **近 1 个月（推荐起步）** | 你几乎每天都在 Codex 里讨论或处理事情，已经积累了不少窗口；想先看看这些内容整理成工作台后的效果。 | 先整理近期内容，确认小结、分类和查找方式是否符合需要，再补充更早的讨论。 |
| **近 3 个月** | 你只是偶尔使用 Codex，最近一个月的内容不多；或者需要一起回看过去几个月持续推进的事情。 | 覆盖更长一段时间。如果每天都有大量讨论，首次整理也可能需要较长时间。 |
| **自选时间范围** | 你已经知道想找哪个时期的内容，例如半年前讨论过的一个方案。 | 直接选择相关日期，不必为了找旧讨论，把中间所有月份都整理一遍。 |

</details>

### 3. 点击固定入口，开始使用

首批整理好后，Codex 会在桌面创建“打开 Codex 工作台”入口，并给你网页地址，随后继续处理选定范围。需要整理的讨论越多、内容越长，首次等待通常也越久；过程中会告知进度，遇到中断会保存恢复点。

以后双击这个入口，就会自动打开网页；服务停止时也会自动恢复，不需要自己运行命令。建议始终在**常用浏览器**使用，先搜索一件你记得的事，点进去核对小结与原话。收藏和“接着做”的确认、移出选择保存在当前浏览器，切换浏览器或网页地址不会自动同步。

**经常从浏览器书签打开？** 可以让 Codex 开启“登录电脑后自动启动”。它只让阅读服务准备就绪，不弹出浏览器，也不会开始整理资料。这个选项默认不开启，之后可以随时关闭。

## 以后怎么更新

平时点击“打开 Codex 工作台”搜索、回看。需要新增内容时，在 Codex 中说：

> 更新一下我的对话整理工作台。

也可以让它补充更早的讨论，或按你的要求设置定时更新：

> 帮我设置每天早上 8 点更新工作台。

首次整理结束后，Codex 会主动询问你是否现在设置定时更新，例如每天早上 8 点。你可以指定其他时间，也可以暂不设置。

网页不是实时同步。定时功能需要 Codex 环境支持，并保持相关运行环境可用；只有你确认后才会创建，不会在安装时自动开启。

## 常见问题

<details>
<summary>会修改原对话，或者把我的内容公开吗？</summary>

不会删改原来的 Codex 对话。工作台文件保存在你的电脑上，安装这个公开仓库也不会把聊天上传到 GitHub。整理仍由你的 Codex 环境处理，不代表 AI 整理完全离线。

分享给朋友时，发送本仓库链接即可，不要分享装有私人内容的工作台文件夹。

</details>

<details>
<summary>能整理全部历史吗？包含 ChatGPT 和图片吗？</summary>

首次由你选择时间范围，实际覆盖取决于当前环境能读取哪些正文。读不到或不完整的部分会说明，不会拿摘要冒充原话。目前整理 Codex 对话，不包含 ChatGPT 对话和附件正文。

</details>

<details>
<summary>重启电脑，收藏会消失吗？</summary>

普通重启通常不会。收藏保存在当前浏览器；清除本站数据、删除浏览器用户配置或结束无痕会话后会丢失。换浏览器或网页地址不会自动同步，适合临时回看。

</details>

<details>
<summary>Windows、macOS 和 Linux 都能用吗？</summary>

网页与整理脚本已做三个系统的兼容处理；固定桌面入口和可选登录自启动面向 macOS、Windows，Linux 可通过 Codex 打开。目前 macOS 已实测，Windows 与 Linux 的验证范围见技术说明。安装时 Codex 会检查必要环境，遇到问题可把提示发给它继续处理。

</details>

<details>
<summary>安装后找不到 Skill，或者网页打不开了怎么办？</summary>

安装后尚未识别 Skill，可以新建对话或重新打开 Codex，再发：

```text
使用 $lukk-codex-workbench，帮我建立对话整理工作台。
```

先点桌面的“打开 Codex 工作台”，它会自动检查并恢复服务。直接点击浏览器书签需要服务已经运行，可按需开启登录后自动启动。

老版本还没有固定入口，或入口弹出错误提示时，对 Codex 说“帮我修复已有工作台的打开入口”。已有内容不用重新整理；把错误提示或启动诊断文件交给它即可。

</details>
